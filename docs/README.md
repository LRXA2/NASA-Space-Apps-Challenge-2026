# Engineering documentation

| [regenerate-export.md](regenerate-export.md) | How to rebuild the app's data after a model or scorer change |
| [demo-walkthrough.md](demo-walkthrough.md) | The demo path, verified examples, and known limits |
| [featured-tiles.md](featured-tiles.md) | The three featured patches per region |
| [team-blockers.md](team-blockers.md) | Questions for each teammate and their recorded answers |
| [specs/app/](specs/app/area.md) | Feature specs, verification records, and decisions |

The [data guide](../data/README.md) lists local inputs and their paths.
The [app guide](../app/README.md) covers app setup, verification, and data export.
