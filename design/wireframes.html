Lunar Analog Finder · low-fi wireframes

Pass 1, revision 3: layout only, greyscale. Target stack is a static React site reading precomputed JSON. Every number is a sample value for layout. Chips show the data source (A similarity CNN, B environment engine, C terrain CNN) and, where it matters, how the component behaves.

What changed in revision 3
  • Stack is now static React (Vite + TypeScript). All Streamlit chips and workarounds are removed.
  • The sidebar becomes a top bar with Region and Patch switchers, so maps and terrain get the full width.
  • The region patch map is a Leaflet CRS.Simple grid: click a 960 m square to open it, hover for its classes.
  • Pair comparison draws all four terrain canvases from grids, on one shared colour scale, with a linked crosshair and live readout.
  • Earth matches sit on a Leaflet lat/lon map, linked to the ranked table on hover.
  • Each screen now has its own URL, listed in the notes below the frame.
