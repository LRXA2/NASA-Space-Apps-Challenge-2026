Score your own environment scenario

Fill in the input template with your own values. Darrel's scorer runs unchanged in this tab and gives each row an Operations and a Survival result, with every gate check.

1

Get the template

The unchanged input file behind the precomputed results: 27 columns, one scenario per row. Fill in id, start_utc and stop_utc yourself; take the rest from NASA data where you can.

Leave a value blank if you don't have it. The scorer runs in strict mode: a blank required input gives Unknown with a reason, never a guess.
