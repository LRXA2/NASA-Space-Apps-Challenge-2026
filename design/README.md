# Design

This folder contains the product brief, wireframes, and visual designs for Lunar Analog Finder.
Engineering documentation and feature specs live in [`docs/`](../docs/).

| File | What it covers |
| --- | --- |
| [PRODUCT.md](PRODUCT.md) | Audience, purpose, and content rules. The root `PRODUCT.md` links here |
| [wireframes.html](wireframes.html) | Clickable layout wireframes, revision 3. All numbers are samples |
| [handoff/design_handoff_2026-11-13.md](handoff/design_handoff_2026-11-13.md) | Screens, routes and UI rules as handed over on 13 Nov |
| [exploration-theme/](exploration-theme/) | [Design values and screen layouts](exploration-theme/DESIGN.md), rendered screens at 1440 and 375 px, HTML/CSS mockups, and sky data |

The app implements the exploration theme in [`app/src/styles/`](../app/src/styles/).
