# Darrel's notebook naming

- Name every newly created notebook `Dar_0xx_descriptive_name.ipynb` (for example, `Dar_001_temperature_local_time.ipynb`). Use the next unused three-digit number across both Earth and Moon folders.
- Keep existing reference/ported notebook names unchanged unless the user requests a rename.
- Put notebooks under the appropriate `Earth/` or `Moon/` folder. Generated data, figures, manifests and execution/debug artifacts belong under `darrel stuff/data/`, not alongside source notebooks.

- Group notebooks as `Earth/<category>/` or `Moon/<category>/` only when that category has more than two notebooks. Leave smaller categories directly under the planet; preserve filenames and data locations.
